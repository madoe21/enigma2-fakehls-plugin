# Branching model: simple

Generated by aiflow from .aiflow/config.json. Change via `aiflow change-settings`.

- **Permanent branches:** main, develop
- **The mainline is named `main`** - not `master`. Every rule below, the pre-push hook,
  `aiflow release` and `aiflow hotfix` reference `main` by name. A repo still on `master`
  is renamed by `aiflow apply` (`git branch -m master main`); push it and switch the
  default branch on your remote, then delete the old `master`.
- **Strict rules:** true   **PR-only:** true   **Auto-release:** false   **chore/*:** true

## Allowed branch creation
- <any temporary> <- from: develop
- chore/* <- from: develop, main

## Allowed merges
- develop -> main
- main -> develop
- chore/* -> develop
- chore/* -> main

## Pull requests
- No direct push to main/develop; merge only via PR; PR must pass validation.

Enforced locally by the `pre-push` git hook; enforce on the server with branch protection (`aiflow protect`).
